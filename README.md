# 简历侧边栏

一个 Chrome 侧边栏扩展。先点击网页中的输入位置，再点击侧边栏里的简历字段，即可填写内容。

扩展使用 Chrome 原生侧边栏，不会覆盖网页。支持普通输入框、文本框、日期、月份、下拉选项、单选框、复选框、可编辑区域和网页中的 iframe。填写失败时会自动复制内容，也可以按住 Alt 点击字段直接复制。

## 安装

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库中的 `extension` 文件夹。
6. 打开招聘网页，点击浏览器工具栏中的“简历侧边栏”。

如果安装前已经打开了招聘网页，请刷新网页后再使用。

## 使用

1. 点击网页中需要填写的输入框或选项。
2. 在侧边栏中展开分类和条目。
3. 点击需要填写的字段。

侧边栏可以切换字号、亮暗模式和日期分隔符。原生日期控件会继续使用浏览器要求的 `YYYY-MM-DD` 或 `YYYY-MM` 格式。

## 修改示例数据

所有简历数据都在 [`extension/data.js`](extension/data.js) 中。仓库提供的是虚构示例，请复制现有结构后替换内容。

普通文本字段：

```js
{ label: '姓名', value: '示例用户', kind: 'text' }
```

日期字段：

```js
{ ...date('2025-06-30'), label: '取得时间' }
```

包含开始和结束日期的经历：

```js
...period(date('2023-09-01'), date('2026-06-30'))
```

日期需要直接写到日。请不要加入自动补日逻辑。

## 使用单独的私人数据文件

如果不希望把真实信息写进公开仓库，可以把私人数据文件放在其他目录，再执行：

```bash
node scripts/build.mjs --data /路径/data.private.js --out /路径/私人构建目录
```

脚本会复制扩展代码，并用私人数据替换构建目录中的 `data.js`。在 Chrome 中加载生成的构建目录即可。私人数据文件和构建目录都不要提交到本仓库。

运行以下命令可以检查公开示例并验证 JavaScript 语法：

```bash
npm run check
```

## 兼容范围

扩展支持 Chrome 114 及以上版本。Chrome 内部页面、Chrome 应用商店、文件上传框、封闭 Shadow DOM，以及没有标准 HTML 或 ARIA 语义的自定义控件可能无法自动填写。

扩展不会自动提交表单，也不会主动向外部服务器发送简历数据。
